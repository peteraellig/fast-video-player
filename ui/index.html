The cue list

  • Add media… or drag files / folders from Explorer into the list. Videos, sound files and still pictures (jpg, png, bmp, gif, tif).
  • Drag rows, the ▲ ▼ buttons or Alt+↑↓ to change the order. New / Open / Save handle playlists (.cuelist).
  • Tags beside each picture: ▶ PLAY = on air, ● NEXT = plays on the next GO (yellow frame), ■ CUED = stopped, its first picture is already on the outputs, ◆ READY = loaded in the background for a gapless follow-up, ⚠ MISSING / ⚠ NO PICTURE = file not found / picture format not supported.
  • Per cue: end action, audio (channel pair, single channel on both sides, track, mute) or the display time of a still picture (1-30 s, ∞).

Playing

  • GO (Space) plays the NEXT cue and moves NEXT on. A click on a row chooses NEXT; while stopped its first picture goes on air at once, so nobody starts on black.
  • Stop (Esc) stops the cue on air and cues the next one. Pause (P) freezes picture and sound. ⏮ ⏭ play the previous / next cue.
  • Last 10 s (L) jumps to 10 s before the end. In the last 10 s a big countdown 10…1 shows over the preview.
  • Double click or Enter plays the chosen cue at once (cut). Click the bar under the clock to jump.
Hold lastthe last picture stays on air (choose another cue to release it)

Cut nextthe next cue follows without a gap
Fade nextthe next cue fades in over the fade time (100-1000 ms, saved with the playlist)
Loop / Loop fadethe cue repeats, with a cut or a fade into its own start
Jump (cut / fade)another cue follows, chosen in the second dropdown (e.g. the last cue jumps to the first: the whole playlist repeats)

Outputs

  • Settings: output format, source name, send as NDI (needs the NDI runtime from NDI Tools), OMT (built in), SDI (Blackmagic DeckLink / UltraStudio, Desktop Video driver) and HDMI (full screen on a second monitor). Changes take effect with Apply.
  • Audio level applies to all outputs; Monitor plays the output sound on a sound card of this PC as well.
  • The header shows the receivers per output (one receiver = one vMix input, for example).

Remote control (HTTP)

Off by default. Switch it on in Remote control: This PC only (programs on this computer) or Network (other computers; optionally only the listed IP addresses). For the network, Windows usually needs a firewall rule: Add firewall rule… (asks for administrator rights). The player never sends anything by itself - a remote asks for the state as often as it needs it (polling, e.g. every 250-500 ms).

Address now: -

GET /api/stateon air (name, position, remaining time, countdown), next, cued, playlist, outputs
GET /api/cuesthe cue list (number, id, name, length, end action)
/api/go /api/stoplike the GO and Stop buttons
/api/pause /api/resume /api/togglepausepause / play on (pause twice stays paused)
/api/next /api/prevplay the next / previous cue
/api/last10 /api/seek/{ms}jump to the last 10 s / to a position in ms
/api/fade/{ms}fade time of the playlist (100-1000)
/api/cue/{n}/playplay cue n now (n = position in the list, 1 = first)
/api/cue/{n}/selectmake cue n NEXT (while stopped: its first picture goes on air)
/api/cue/{n}/endaction/{a}a = hold, black, next, fade, loop, loopfade
/api/cue/{n}/endaction/jump/{m}at the end jump to cue m (jumpfade instead of jump: with a fade)
/api/cue/id/{id}/…the same by the cue's fixed id (stays right when the list is reordered)

Every command works with GET (a plain link) or POST. The answer is JSON: {"ok": true, "command": "go"}, errors with "ok": false and the reason. GET /api lists all addresses. For safety, requests that another web page makes in a browser are refused (an address typed into the browser or a bookmark works, as do Companion, vMix, Stream Deck and scripts).

Examples

Browser - open the state or press GO:

{URL}/state
{URL}/go

Bitfocus Companion - module Generic HTTP, connection to the player PC; a button with the action GET and the address:

{URL}/go
{URL}/cue/3/play
{URL}/stop

For button text or colours, let Companion poll {URL}/state as JSON and read for example onAir.name, onAir.remainingMs, onAir.countdown or state.

vMix - a script (Settings → Scripting, VB.NET), started from a shortcut or a trigger:

Dim web As New System.Net.WebClient()
web.DownloadString("{URL}/go")

Stream Deck - action Website with "GET request in background" and the address {URL}/go.

PowerShell:

Invoke-RestMethod {URL}/cue/2/play
(Invoke-RestMethod {URL}/state).onAir
